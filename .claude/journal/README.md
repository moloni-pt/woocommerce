# Journal

Recent, **unverified** findings — one dated file per finding (`YYYY-MM-DD-<slug>.md`), each written as
`symptom → cause → rule`. They are leads, not rules: once re-verified against the code they are promoted
into `AGENTS.md › Gotchas` and the fragment is deleted.

Only record what the code, the tests and `AGENTS.md` don't already make obvious.
